# SFB:GO

Arkadaşlar arası, en fazla 10 kişilik, sınıf tabanlı free-for-all FPS. Godot 4 ile yapılıyor.

- Tasarım: [docs/GDD.md](docs/GDD.md)
- Kod yapısı: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Durum: [docs/PROGRESS.md](docs/PROGRESS.md)

## Oynamak için

1. [Releases](../../releases) sayfasından son sürümün zip'ini indir, aç, `SFB-GO.exe`'yi çalıştır.
2. Host ve oyuncular aynı Tailscale ağında olmalı.
3. Host: **Host Game**. Diğerleri: **Join Game** → host'un Tailscale IP'si.

## Geliştirme

- Godot 4.4+ ile `project.godot` dosyasını aç.
