## How to play (Windows)

1. Download the `SFB-GO-...-windows.zip` below and extract it anywhere.
2. Run `SFB-GO.exe`. Windows may warn about an unknown publisher (the game is not signed): **More info → Run anyway**.
3. Host: **Host Game**. Friends: enter the host's IP and **Join** (port 7777, UDP).

## What's new

- Third-person animations (Mixamo): other players now idle, run (forward / back / sideways / diagonal), crouch-walk, jump, fall, fire and aim up / down. The body you see stays lined up with the hitboxes.
- Death animation: players fall down where they die, the body fades after a few seconds.
