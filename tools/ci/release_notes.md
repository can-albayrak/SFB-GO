## How to play (Windows)

1. Download the `SFB-GO-...-windows.zip` below and extract it anywhere (keep `steam_api64.dll` and `steam_appid.txt` next to the exe).
2. Run `SFB-GO.exe`. Windows may warn about an unknown publisher (the game is not signed): **More info → Run anyway**.
3. **Steam:** everyone has Steam open and signed in. Host: **HOST ON STEAM** in the Steam panel. Friends: **FIND STEAM GAMES** → JOIN, or accept the host's Steam invite (INVITE in the lobby).
4. **IP (no Steam needed):** Host: **Host Game**. Friends: the host's IP → **Join** (port 7777, UDP).

## What's new

- Player model: Saul Goodman, animated with the Mixamo clips (idle, run in every direction, crouch, jump, fall, fire, aim up/down, death).
- Others now see what you do: guns held with both hands and aimed where you look, reloads (magazine reload on rifles, gun tipped up on shotguns/revolvers/pistols/launchers), grenade and knife throws, knife swings.
- Small name over every player's head; an airdrop carrier's name is orange and shows through walls (replaces the big weapon label).
- Sniper rifles are bigger in first person.
